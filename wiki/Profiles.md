# Profiles

- `safe`: all entries independently reviewed as OpenCode v2-compatible.
- `safe-search`: Tavily and local/codebase indexing tools.
- `safe-operations`: quota, memory, orchestration, and notifications.
- `productivity`, `memory`, `ui`, `workflow`: focused groups.
- `source-builds`: explicit opt-in only; requires pinned source build approval.

Use `--dry-run` before any install. Risky or unverified entries are never silently included.
