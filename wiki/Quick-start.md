# Quick start

First verify OpenCode v2 is installed:

```bash
curl -fsSL https://raw.githubusercontent.com/Alqudimi/opencode-atherbox/main/install.sh | sh -s -- doctor
```

Open the interactive terminal menu:

```bash
curl -fsSL https://raw.githubusercontent.com/Alqudimi/opencode-atherbox/main/install.sh | sh
```

Choose a profile, preview the changes, then confirm installation. To remove only extensions managed by this tool, choose **Remove** from the TUI or run `opencode-v2-extensions remove` from a checkout.
